# Python Mastery Assignment
Parts 1 to 12 are single files: `part01_variables.py` ... `part12_testing.py` (each has Warm-up, Build and Challenge sections).
Extra files: `part07_read_results.py` (Part 7 second program), `part08_build/` (Part 8 module + main.py), `test_grades.py` and `test_bank.py` (Part 12 tests).
`school_app/` is the Part 8 package layout and the Final Project (School Manager), with its own README and tests.
Run any part with `python partXX_name.py`. Run the Part 12 tests with `pytest -v`. Run the final project tests inside `school_app/` with `pytest -v`.
Python 3.10 or newer is needed.
